# Harikatha Studio

A local, audio-only story-to-Harikatha studio. Paste a story, create an editable performance script, generate expressive spoken narration, and download a WAV mixed with an original tanpura-inspired drone and soft synthesized bell accents. It does not create video.

## Start it

1. Install Python 3.10 or newer if it is not already installed.
2. Double-click `run.bat` (or run `python server.py` from this folder).
3. The app opens at `http://127.0.0.1:8765`.
4. Add a story and choose **Compose my Harikatha**. With no API key, the app uses its local same-language formatter and the built-in Windows speech voice. If you have an OpenAI API key, paste it to use the cloud models instead.

Use `run.bat` for the working app; opening `index.html` directly can show the interface, but the story and speech API routes require the local server.

If provided, the key is sent from the browser to this local server for the API requests. The server binds only to `127.0.0.1`, does not save the key, and does not save stories, scripts, or audio. Generated audio is mixed in your browser; use **Download WAV** to keep it. OpenAI API usage may incur charges and is billed separately from ChatGPT subscriptions.

## What the project makes

- **Performance script:** a Harikatha-inspired spoken adaptation with audience address, expressive turns, reflection, and a closing. Choose a devotional, universal, or source-faithful treatment.
- **Narration:** generated by a text-to-speech model with performance instructions for warm, measured, expressive storytelling. The selected voice and spoken style are AI-generated, not a recording of a human Harikatha performer.
- **No-key local mode:** creates a lightweight same-language script draft and uses the Windows built-in speech voice. It does not translate stories or use cloud AI; the performance length follows the source story.
- **Music bed:** synthesized in the browser from tonic/fifth/octave tones with quiet upper partials and occasional bell-like accents. Change the tonic and music level to re-mix the same narration without another speech API request.
- **Exports:** editable script as `.txt` and mixed audio as stereo `.wav`.

The default models are set near the top of `server.py`. The text model can be changed with `OPENAI_TEXT_MODEL`; `OPENAI_TTS_MODEL` only accepts models supported by the Audio Speech API. The app uses the OpenAI Responses API for script generation and the Audio Speech API for voice generation. The [official OpenAI text-to-speech documentation](https://developers.openai.com/api/docs/guides/text-to-speech) currently marks `gpt-4o-mini-tts` as deprecated with a January 6, 2027 shutdown date. OpenAI's recommended replacement uses the Realtime API, which has a different workflow; this project will need a code update to keep voice generation working after that date.

## Notes

- The browser needs an internet connection for OpenAI API requests and for the Google Fonts used in the interface; the local app itself has no third-party package dependencies.
- The accompaniment is an original synthesized drone, not a recording or a full raga/tabla arrangement. It is intentionally kept beneath the narration.
- Longer scripts are sent to speech generation in short passages and joined in the browser before mixing.
- Use a recent Chrome, Edge, or Firefox browser for audio rendering and WAV export.

## Files

- `server.py` — local-only web server and OpenAI API proxy
- `index.html`, `styles.css`, `app.js` — user interface, browser audio synthesis/mixing, and downloads
- `run.bat` — Windows launch shortcut
